# Annotated Transcripts — every stumble, error, and unnatural phrasing

This is your verbatim error log. Each session, the App coach reproduces the
notable moments of what **you actually said**, marks each problem inline, and
explains the fix. The oral-english-practice skill appends the coach's
"ANNOTATED TRANSCRIPT" output here (newest on top) and mines it for patterns.

---

## Annotation legend

Inline, the problem span is followed by a tag in brackets, e.g. `I go[G1] there`.
Below the line, each tag is explained with the natural fix.

| Tag | Meaning |
|---|---|
| **[G]** | Grammar error (tense, articles, agreement, prepositions...) |
| **[V]** | Vocabulary gap — couldn't find the word, or used the wrong one |
| **[N]** | Unnatural / not idiomatic — technically correct but not how natives say it |
| **[F]** | Fluency stumble — filler ("uh/um"), false start, repair, long pause |
| **[P]** | Pronunciation issue the coach noticed |

Number within type to disambiguate: G1, G2, V1, N1, F1, P1...

---

## Format (one block per session)

```
## YYYY-MM-DD — Session NN
Topic: ...

Me: I go[G1] to the mall yesterday and I want[G2] to buy a jacket, but I
didn't know how to say 试穿[V1], so I just said "I want to wear it first"[N1],
and then, uh... uh...[F1] the staff looked confused.

  G1  go → went (past simple — the whole story is in the past)
  G2  want → wanted
  V1  试穿 = "try it on" (phrasal verb). "Can I try this on?"
  N1  "I want to wear it first" → native: "I wanted to try it on first"
  F1  long filled pause — practice pausing silently instead of "uh"

Coach note: tense control breaks down under pressure — today's main leak.
```
