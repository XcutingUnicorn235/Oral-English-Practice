# Mistake Bank

Confirmed recurring errors, kept so they get re-drilled until fixed. A pattern
enters once it shows up in **≥2 sessions** (or **≥3 times in one session**).
`struct` (grammar/pronunciation/filler) patterns resolve after **2 clean
sessions**; `lex` (specific-vocabulary) patterns only resolve after 2 sessions
in which next-focus actually re-tested them (random topics otherwise hide them).
Resolved = archived, not deleted. The skill maintains this table from each
session's transcript, matching patterns on the stable `key`. See
`references/data-format.md` for the exact rules.
