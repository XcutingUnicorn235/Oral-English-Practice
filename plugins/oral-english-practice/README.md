# oral-english-practice (plugin)

This is the packaged Claude Code plugin for **Oral English Practice**. It bundles
one skill, `skills/oral-english-practice/`.

- **Full documentation:** see the [repository README](../../README.md)
  ([中文](../../README.zh-CN.md)).
- **Changelog:** [CHANGELOG.md](../../CHANGELOG.md).

## Install

From the marketplace this repo defines:

```
/plugin marketplace add XcutingUnicorn235/Oral-English-Practice
/plugin install oral-english-practice@xcutingunicorn235
```

Then run `/oral-english-practice` in Claude Code (or say "I want to practice
spoken English"). Your practice data is created on first use in a separate,
clearly-named folder — see the repository README for details.
